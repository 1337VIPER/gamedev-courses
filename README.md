# Game Dev Courses

Interactive, click-by-click courses for Blender and Unreal Engine, each lesson built around a real production result.

**Live site:** https://1337viper.github.io/gamedev-courses/

| Course | Status |
| --- | --- |
| [Geometry Nodes Fast Track](https://1337viper.github.io/gamedev-courses/geometry-nodes/) (Blender 5.3) | Module 1 (4 lessons) |
| Real-time VFX with Niagara (Unreal Engine) | In production |
| Compositing in Blender | In production |

Progress (ticks, notes, best times) saves in your browser. To keep it in a file instead, run a course locally:

```
python geometry-nodes/serve.py
```

then open http://127.0.0.1:5177 and progress is written to `progress.json` next to the page.
